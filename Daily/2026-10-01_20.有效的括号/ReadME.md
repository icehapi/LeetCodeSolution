# 20.有效的括号

🔗 [题目](https://leetcode.cn/problems/valid-parentheses/description/?envType=daily-question&envId=2026-10-01)

## 题目大意

给定一个只包含 `(, ), [, ], {, }` 的字符串 `s`，判断这个字符串是否有效，即左括号在右括号前、括号必须按顺序闭合。

## 解题思路

方法：栈

1. 遇到左括号入栈。
2. 遇到右括号时，判断栈是否为空、栈顶是否为对应类型的左括号。
3. 遍历完 `s` 时，判断栈是否为空。

## 复杂度分析

- 时间复杂度： $O(n)$，其中 $n$ 是 $s$ 的长度。
- 空间复杂度： $O(n + |\Sigma|)$，其中 $\Sigma$ 是字符集长度，本题中字符串只包含 6 种括号，$∣\Sigma∣= 6$ 。栈中的字符数量为 $O(n)$，而哈希表使用的空间为 $O(∣\Sigma∣)$，相加即可得到总空间复杂度。如果不使用字符集则可省下这个空间。
